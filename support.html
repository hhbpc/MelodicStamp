帮助与支持

最后更新日期：2026年6月18日

Melodic Stamp 是一款专为 macOS 设计的原生音乐播放器，完全运行于沙盒环境，不扫描无关目录，不联网收集数据。它拥有强大的音频兼容性，并深度支持 TTML 逐字歌词、LRC 增强型翻译/注音，为您提供纯净、沉浸的本地音乐体验。

致歉信

真的非常抱歉，Melodic Stamp 在 4 月底突然从 App Store 下架，相关宣传文章和视频也一并隐藏，给大家带来了困惑与不安。

起因是 Apple 在 macOS 26.4 中对 SwiftData 做出了一些未被明确的改动，导致软件在 26.4 至 26.5 的系统版本上出现了较为严重的稳定性问题，在更早的系统版本中 SwiftData 也依然带来部分不稳定的行为。

Melodic Stamp 是我完全利用业余时间独立开发的作品，由于个人精力和时间实在有限，我没能做到第一时间紧急修复，这并非敷衍，更绝不是想要坑骗任何一位用户。

为了不让更多人在不知情的情况下受到影响，也为了能够沉下心来彻底解决问题，我选择暂停销售并暂时隐藏了宣传内容。对于这一决定给您带来的失望与不便，我发自内心地感到抱歉，同时也深深感谢您一直以来的包容和支持。

关于本次更新，1.2.0 版本进行了完整的数据库重构，彻底移除了对 SwiftData 的依赖，从根本上解决了此前由此引发的各种异常崩溃。与此同时，这一版也补全了 1.1.0 中承诺过的全部功能，并提供了相对完善的数据库迁移方案。希望这一次，能不负您的等待与信任。

再次感谢您对本软件的喜爱和开发者的理解和包容。

存储

如何通过文件夹导入？

执行以下任一操作：

• 快捷键 Command + L 打开文件夹选择器，选中音乐目录；
• 点按"点击添加文件夹"按钮，或直接拖拽文件夹至导入区域。

Melodic Stamp 仅扫描您主动添加的文件夹，不会读取任何其他位置。详见下方 快速上手。

如何挂载 Jellyfin？

从 1.2.0 版本开始，Melodic Stamp 支持连接 Jellyfin 等自托管网络音乐服务。在应用设置中添加您的 Jellyfin 服务器地址并登录账户，即可挂载网络媒体库。

首次连接时应用会请求网络权限，仅用于与您自己的服务器通信，您的数据不会上传至任何第三方服务器。

导入文件夹后无法扫描到音频文件？

请依次检查：

• 确认文件夹是通过系统文件选择对话框或拖拽方式主动添加的（沙盒授权要求）；
• 确认音频文件格式在支持范围内（见 音频格式支持）；
• 确认文件夹位于内置或直连本地存储，暂不支持 NAS、网络驱动器或挂载存储设备；
• 可在设置中尝试"强制重新扫描元数据"或开启"启动时刷新"。

若仍无法解决，欢迎邮件联系开发者反馈。

如何从 SwiftData 迁移数据？

1.2.0 版本对数据库进行了完整重构，彻底移除了对 SwiftData 的依赖。升级到 1.2.0 后，应用提供了相对完善的数据库迁移方案，按应用内提示操作即可将旧数据（收藏、歌单、播放统计等）迁移到新数据库。

建议在迁移前备份媒体库，以防意外。

安装、测试、购买、退款

安装

目前您可以通过 TestFlight 连接加入测试队列。

  • App Store 正式版 — 稳定可靠，通过 macOS App Store 直接获取。
  • TestFlight 测试版 — 抢先体验新功能，名额有限，需接受潜在不稳定风险。加入测试前建议备份媒体库。
    注意：测试版与正式版可相互替换（构建号后两位高者可覆盖，否则需卸载重装）。

音频格式支持

Melodic Stamp 兼容几乎所有主流无损及有损格式，无需转码：

FLACMP3Ogg Opus/VorbisDSF / DSDIFF (DSD64, DoP) Monkey's Audio (APE)WavPackTrue AudioShorten WAV / AIFFMusepacklibsndfile 系列

歌词格式支持

精准显示原文、翻译、注音，支持逐字点亮与多轨对唱。

  • TTML — 逐字 / 逐行歌词，支持对唱、背景歌词，兼容 AMLL TTML Database 与 Apple Music 逐字注音规范。
  • LRC — 基础歌词、逐字型 LRC、增强型 LRC（社区扩展格式：支持原文 + 翻译 + 注音连续或分段排列）。
    注：LRC 若仅提供注音行而无翻译，注音会被识别为翻译，属格式限制。
  • 内嵌歌词 — 读取音频元数据（ID3 Lyrics）中的歌词。

快速上手

1. 导入音乐文件夹
执行以下任一操作：
• 快捷键 Command + L 打开文件夹选择器，选中音乐目录。
• 点按"点击添加文件夹"按钮，或直接拖拽文件夹至导入区域。
Melodic Stamp 仅扫描您主动添加的文件夹，不会读取任何其他位置。

2. 歌词自动匹配
应用会在导入的文件夹（含子文件夹）内，查找与音频文件同名的歌词文件。
匹配优先级：.ttml 优先，其次为 .lrc 或 .txt 。若同时存在外置歌词与内嵌歌词，默认优先使用外置歌词（可在元数据编辑器中调整）。

3. 开始播放
点击曲目即可播放，媒体库支持收藏、歌单、专辑及艺术家视图。还可通过菜单栏图标快速控制或显示当前歌词。

隐私与安全核心

本应用仅在您连接 Jellyfin 等自托管网络音乐服务，或通过 艺人信息补全 时才会请求网络权限（1.2.0 版本起）。其余所有数据均存于本地沙盒，绝不收集个人信息或上传音频，卸载即清除。元数据编辑器会直接修改音频文件，建议编辑前备份重要文件。

个性化设置

通过 设置 (⌘ ,) 可深度定制体验：

  • 窗口背景 — 纯色 / 活力 / 空灵，调整模糊与混色效果。
  • 歌词显示 — 独立开关翻译、注音，支持粗体、淡出效果，实验性歌词渲染器（TextRender）可提升逐字精度。
  • 菜单栏歌词 — 显示当前歌词或光碟图标，支持逐字动画（占用稍高，属正常现象）。
  • 媒体库 — 文件夹自动观察、启动时刷新，可强制重新扫描元数据。
  • 待播清单记忆 — 重启后恢复播放队列及进度。
  • 悬浮窗/常亮 — 专注歌词页时可防止屏幕休眠。

本应用不提供云端歌词下载或识别，所有歌词需自行准备。但完善的本地匹配机制让您的歌词库井然有序。如需反馈问题或功能建议，欢迎邮件联系。
